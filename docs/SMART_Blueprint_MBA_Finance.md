# SMART — Role Assessment Blueprint: MBA — Finance

### Domain → Sub-Domain → Concept, weighted, mapped to L1–L5

**Grounding note:** BFSI hiring for MBA finance roles remains one of the strongest fresher categories in 2026, with post-rate-cut BFSI demand cited as a specific growth driver, alongside fintech-oriented finance roles growing across sectors. Finance sits just behind Business Analytics as a top-demand MBA specialization in current hiring indices.

**Calibration note:** concept-level weights are the calibration panel's first-pass judgment of relative importance, to be validated against real regional hiring data — not a fixed psychometric fact.

---

## Level weightage summary

| Level | Composition                                                                                                          |
| ----- | -------------------------------------------------------------------------------------------------------------------- |
| L1    | 40% general aptitude (quant-weighted) + 20% Domain A + 20% Domain B + 20% Domain C                                   |
| L2    | 35% Domain C (applied modeling) + 30% Domain B (applied valuation) + 20% Domain A (applied analysis) + 15% Domain D  |
| L3    | 100% Domain E                                                                                                        |
| L4    | AI-assessed threshold model (see universal L4 methodology) — artifact/case-work upload + adaptive simulation defense |
| L5    | 50% checklist + 30% practitioner judgment + 20% presentation                                                         |

## Level 5 — Capstone

A real, anonymized company's financials, analyzed end-to-end — statement diagnostics, a working valuation model, and a final investment/lending recommendation, defended in a short presentation. Scored 50% checklist / 30% practitioner judgment / 20% presentation.

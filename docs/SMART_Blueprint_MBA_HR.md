# SMART — Role Assessment Blueprint: MBA — Human Resources

### Domain → Sub-Domain → Concept, weighted, mapped to L1–L5

**Grounding note:** HR is flagged in at least one 2026 sector-hiring index as the slowest-growing MBA specialization relative to Business Analytics, Finance, and Product Management this cycle — worth stating plainly rather than glossing over, since it changes the honest framing of this track's confidence note versus the others. It remains, however, a consistently named, real hiring category across every source reviewed, with steady demand from IT services and FMCG in particular.

**Calibration note:** concept-level weights are the calibration panel's first-pass judgment, to be validated against real regional hiring data.

---

## Level weightage summary

| Level | Composition                                                                             |
| ----- | --------------------------------------------------------------------------------------- |
| L1    | 40% general aptitude (verbal-weighted) + 25% Domain A + 20% Domain B + 15% Domain C     |
| L2    | 30% Domain A (applied) + 25% Domain B (applied) + 25% Domain C (applied) + 20% Domain D |
| L3    | 100% Domain E                                                                           |
| L4    | AI-assessed threshold model — artifact/case-work upload + adaptive simulation defense   |
| L5    | 50% checklist + 30% practitioner judgment + 20% presentation                            |

## Level 5 — Capstone
